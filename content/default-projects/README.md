# 默认工程内容包

此目录随 World Atelier 部署，包含 9 个游戏、11 个分支。2026-11-02 的 9 个主干均包含 Three.js Web 实现。首款「贪吃蛇」保留 68 个原文件，随后八款保留 625 个原文件并新增 47 个 Web 文件。两个非主干分支保留原版。启动器自动将它们安装到中央创作存储，注册后即可只读浏览和试玩。

`catalog.json` 是带哈希的内容目录；`objects/` 是完整原生源文件、对应引擎查询索引及封面的去重压缩分片，不包含用户数据库、聊天、凭据、存档或游戏构建产物。安装时校验并还原原始字节，原生文件仍是内容权威。

不要手改压缩对象或独立修改查询索引。维护内容请使用 `tools/export-default-projects.mjs` 从中央源稿导出到新的空目录，核对后替换此包。现有部署不会因包更新而覆盖已有工程。

详细范围、权限和更新约定见 [默认工程分发](../../docs/DEFAULT-PROJECTS.md)。
