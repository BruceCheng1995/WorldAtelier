# Noto Sans SC

Unmodified Noto Sans SC variable TrueType font from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosanssc

Downloaded file: `NotoSansSC[wght].ttf`, stored as `NotoSansSC.ttf`.
License: SIL Open Font License 1.1, included in `OFL.txt`.

The actual Godot HUD and Label3D nodes use this bundled font, including Chinese collaborator names and task titles. It is packaged into Web/native exports; it does not depend on a user's operating system fonts.
