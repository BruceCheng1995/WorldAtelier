# 2026-10-23 创作能力：独立验收计划

依据 `docs/CREATION-NEXT-WAVE-2026-10-23.md`。本文件是当前开发范围的独立测试计划，不是功能完成记录，不增加产品自动验证 Agent、保存门禁或验收面板。执行状态初始为 `not_ready`；只有对应实现和接口交付后才执行。

## 角色、环境与证据

- 主集成在原工程负责运行隔离、公共入口和客户端接续；开发工作区分别负责合并/离线与观察/分支上下文。独立测试角色不修改被测功能实现。
- 唯一产品入口仍为 48910。本计划不启动、停止或改写正式服务和数据。48921 由独立测试串行使用；端口被占用时退出，不停止占用者。
- 新数据库、新账号、新源工程、新世界和独立浏览器上下文。进程只能关闭本轮创建的 PID/进程组，收尾核对其退出和监听释放。
- Godot 使用 `--headless --audio-driver Dummy`；必要视觉检查只用现有 `--wa-render` 启动器。浏览器使用 headless Chrome 与 `--mute-audio`，不占用用户桌面输入。
- 重型真实 Web 导出/共享权威运行须先与主集成协调；纯 Node 与各自临时 SQLite 检查可并行。
- 每轮记录代码 HEAD、dirty/new 被测源码的 SHA-256、工具版本、测试来源工作区、固定源/构建/运行身份、实际地址和环境开关。报告不写令牌、Cookie、管理员凭据或私人消息正文。
- 保存初次失败与修复后新结果，不修改历史报告；分别记录 `not_ready / not_run / running / passed / failed / blocked`。缺能力、缺环境或跳过均不计通过。

初次只读环境核对：Node 26.3.0、Godot 4.6.stable.official.89cea1439、Codex CLI 0.163.0；Playwright 1.63.0 可导入，bundled Chromium 缓存不存在，系统 Chrome 存在。后续使用 `channel: 'chrome'`，不为本轮擅自升级工具链。真实模型可用性、Web 模板与 runtime host 的本机/LAN可达性仍需单独验证。

| B：真实 headless 浏览器 | origin/存储/Cookie边界、WebGL画面、UI操作、跨源桥、Web运行 | 任意平台、真实 Agent 修改目标 |
| C：真实 Codex | 实际 thread/turn/tools、按需读取观察、真实源修改与续聊 | 未亲自运行的玩法或所有观察内容的真实性 |

协议负例可以使用明确标注的测试替身。正向运行验收必须记录真实 Godot 的应用确认与状态，不得由驱动注入 `ready/loaded/applied/world_ready` 来制造通过。UI验收不得通过直接设置产品模式变量、数据库完成态或源结果替代实际操作。

## 一套真实作者工程

独立创建小而完整的两场景工程：A 场景有可交互的门、点击次数与移动角色；B 场景有另一同名门及计数。包含稳定源节点、同一预制件两个实例、原生 Control、运行生成/消失实例，以及未知资源/注释/二进制资产。

- 独立 Play 从初始状态启动；作者脚本提供确定的普通输入和可观察效果，不由测试直接写结果。
- 专用共享分支使用明确 `wa_shared` 声明、真实动态角色/玩家所有权、场景切换与存档状态。
- 故意缺陷仅为“门未按用户输入打开”，由真实 Agent 根据发送的上下文修复。验收先记录失败现象，再保存修复、明确重开并检查效果；不提前写修复。
- 恶意作者安全探针只访问本轮测试页面、假账号数据和隔离服务，尝试读创作存储/父DOM/管理API/伪造桥消息；只输出成败、HTTP状态和错误类型，不输出令牌或内容。
- 一份带历史存档的独立运行用于迁移/导出；存档先由真实作者输入形成，不由数据库或测试直接写入奖励/进度。

## 执行顺序与接口等待

1. 先由各开发角色交付最小API/模块契约、错误码和固定身份字段；独立测试写对应 `next-wave-*` 驱动，不凭计划猜接口或提前宣告通过。
2. 先执行Node/临时SQLite负例，问题反馈开发者修复；独立角色不修改产品以使测试通过。
3. 串行启动48921实际HTTP服务，完成运行授权/观察/合并/离线/隐私API；此批不自动计入Godot或浏览器通过数。
4. 协调固定最终输入后执行一套真实Web导出、共享权威与双浏览器旅程，复用同轮固定输入；跨源网络和真实ACK单独留证。
5. 确认观察包确实来自浏览器后运行真实Codex最短修复旅程和目标分支续聊，记录工具调用/提交/实际运行，不注入答案。
6. 重读最终差异，必要窄回归；汇总每层通过、失败、未执行和剩余边界。关闭拥有的所有测试进程，核对48921释放。

测试报告默认保存在 `.local/creation-verification/next-wave/<run-id>/`，其中至少包含 `run.json`、逐case报告、来源哈希清单、脱敏服务日志及实际截图/工程回执的索引。真实执行材料保留在本地，不入Git。
