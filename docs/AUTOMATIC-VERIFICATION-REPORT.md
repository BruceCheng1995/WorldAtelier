## 已实现的行为

- 开发运行完成后，服务自动收集受影响资源，执行 Godot 技术检查，再由独立验证 Agent 检查目标行为。手动编辑也会触发合并后的资源检查。
- 目标面板显示开发、自动检查、应用三个独立事实；不再要求填写表单、采证或人工点击通过。
- Agent 执行问题、真实权限/输入请求、自动检查结果、Godot Web 与权威世界故障、构建和后端操作异常统一进入 Inbox。
- 场景、预制件、对象树和检查器显示对应问题标记。详情支持定位原资源、打开原会话/真实请求、查看构建或重试检查。
- 已读是个人阅读状态；修复状态依赖实际后续结果。权限、源版本、构建、世界与对象地址独立校验，私有正文不随共享问题标记传播。
- 自动证据以哈希保存并纳入备份和恢复；中断后的验证执行需要先核对旧线程和命令，不会重复启动未确认停止的检查。
