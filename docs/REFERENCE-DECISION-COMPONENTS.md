`@` 对象、`@@` 预制件/系统、`$$` 知识共用 reference-components 组件。输入框使用行内标签；消息、过程消息和附件记录使用相同标签。悬停延迟 220ms 或键盘聚焦显示固定快照说明，点击查看已有详情。历史对话框里的预览挂载到该 dialog，避免被原生顶层遮住。名称与说明转义后显示。

正文持久化 `[[ref:attachment-id]]`，引用真实不可变附件。发送时校验所有引用均属于当前草稿，执行文本展开为名称和 attachment ID，保留同名对象之间的区别；历史保留原 token 和快照。重复发送仍使用原请求指纹。旧消息不按同名文字猜测身份，已有附件直接显示为引用标签。删除正文中的引用位置时，附件仍在输入面板的引用栏显示，可用移除按钮从草稿移除。显式移除同步清除相应行内位置；删除失败保留原草稿。
