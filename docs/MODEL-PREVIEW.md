# 真实模型预览接入

2026-09-07。工作台主视口与对象预览已从设计 SVG 升级为两个持久的 Godot 4.6 Web 实例，共用真实 GLB 资产。入口 `http://127.0.0.1:48910/creation-workspace.html`。

## 运行与文件

```sh
npm run build:preview
npm run start:preview
```

需要已安装 Godot 4.6 和对应 Web export template。构建产物在忽略目录 `.local/model-preview/build/`。模型已随源文件提供，不需要在启动时运行 Blender；可通过 `tools/generate-preview-models.py` 重建六种模型，详细参数见脚本。此服务只监听本机，不占用中央服务 48900。

- `apps/creation-workspace/`：实际工作台、两视口桥接、本地布局草稿与导入交互。
- `runtimes/model-preview/`：GLB 解析、网格三角拾取、相机、选择包围框与 XYZ 操作柄；协议见该目录 README。
- `services/preview/`：页面/运行时/模型服务，结构校验及按 SHA-256 保存上传资产。
- `content/model-preview/`：六个原创 Blender 模型、来源、尺寸与文件哈希清单，总计 767264 字节。
- `docs/design/creation-workspace.html`：保留的历史设计稿，不再作为此 URL 的服务内容。

## 已接入的交互

工作台默认只有场景树、主视口与属性三栏，占满窗口。右上角「聊天会话」展开右侧抽屉，关闭/按 Esc/点击场景收起；开关不会重载模型或清空本页会话草稿。添加对象附件会自动打开指定会话。聊天原先占用的底部行已移除，顶部栏合并为一行。

主场景实际呈现浮台、导航信标、星门、珊瑚树；目录中的探索艇与观测仪也有真实模型，可独立打开或放入场景。场景实例和预制件定义使用各自的文档与布局，不会因查看未放置预制件而替换主场景定义。对象预览用独立相机居中查看同一模型，保留导入材质。

左键点选真实模型；W 移动、E 旋转、R 缩放、Q 选择。移动箭头/平面、旋转环和缩放柄对应完整 TRS 数值字段。右键或 Alt+左键环绕，中键/Shift+右键平移，滚轮缩放，F 聚焦选中、Shift+F 查看全场。Ctrl 临时吸附，Shift 精细拖动，Esc 取消，Ctrl/⌘ Z 撤销变换。对象预览保留直接左键旋转，使用独立相机。完整约定与参考见 [3D 交互](3D-INTERACTION.md)。选择包围框/锚点是编辑辅助绘制，不计入美术模型网格数量。

导入仅接受自包含 GLB，最大 20 MB。文件经过容器校验、真实 Godot GLTFDocument 解析、对象和主场景两处加载后，才更新本页引用。坏候选保留原场景和资产引用。每个 iframe 独立检查来源、origin、nonce 和递增序号；切换目标后旧加载/拖动消息不能写入新对象。拖动预览与已提交布局分开，只有 commit 写入布局。

## 验证证据及范围

浏览器 CUA 已实际看到两处 GPU 画面：初始场景 163 个模型 MeshInstance3D，对象信标 25 个；选择星门后对象视口为 31 个。通过界面调整 X 坐标，实际场景模型移动。使用原生文件选择器导入探索艇，两个视口真实换件成功；再导入完整 BIN 但 POSITION accessor 非法的 GLB，Godot 实际返回 Parse error，原探索艇引用和画面保留。该错误是刻意注入的恢复用例，不是正常页面初始化错误。

最终浏览器又实际完成 Y 轴手柄拖动（0.2 → 3.163 m）、网格点击选择、两处独立相机旋转/滚轮缩放、快速切换探索艇/观测仪以及分支目标切换；iframe 数量保持 2，切换没有重建浏览器运行时。

独立测试通过 14 项 HTTP 检查、7 项 GLTF 结构检查和 20 项连续加载器检查。测试发现失败候选可让缓存达到 47 项；修复后同一用例稳定为 32，并保留旧场景，整组复跑 20/20 通过。六个资产真实解析、有限包围盒与哈希均通过；结构测试不替代浏览器画面。`loaded` 事件始终带 `render_verified:false`，只说明资源解析/节点安装，不能自称 GPU 帧已验证。

最终构建 ID：`c9a06fe862d3a4ee424c9798eb4cf19b2012225722ccd381af8950da5ea3cd2c`。构建日志及本地证据位于 `.local/model-preview/verification/`。

本次接入是静态模型与布局编辑。工作台中的 Play 仍禁用；游戏逻辑、真实多人同步、服务器分支与 Agent 执行待接入。个人检查只是本地布局只读快照，不证明多人游玩暂停。会话及布局在页面内存中，刷新会重置；上传 GLB 保存到本机忽略目录。未完成完整创作旅程验收。

模型不播放动画，不提供骨骼变形后的拾取。当前对象为文档根层级，未实现嵌套预制件覆盖、全工程撤销、服务器版本提交；当前撤销仅覆盖按文档隔离的本页变换事务。两份 WebAssembly 实例有内存成本；单资产 20 MB、渲染器每场景至多 400 个对象、解析缓存至多 32 份，仍需大场景专项性能验证。没有把此工作台公开部署。
