# 产品目标、流程与进度

2026-09-07；产品设计基线。配套：[用户体验 Case](USER-EXPERIENCE-CASES.md)。

**一句话：多人在同一个世界里，用对话和直接操作共同制作游戏，随时在当前网页视口试玩、指出问题、继续修改。**

**主流程：**创建游戏 → 对话创建场景 / 预制件 → 共同摆放与编辑 → 当前视口 Play → 个人检查、附对象 / 坐标 → Agent 修改 → 继续试玩。

**分支流程：**从指定版本分出 → 独立创作和试玩 → 比较、处理冲突、合并 → 两边继续开发。主干和分支使用相同工作台。
