# 顶部协作与 Agent 会话

2026-09-07 · 交互设计提案，使用本页演示状态，无真实 Agent 执行或后端连接。

[打开可点击设计稿](topbar-agents.html)。以原工作台为参照，只在独立设计文件中试验顶部和会话入口；正式工作台尚未集成。

## 布局

顶部 58 px，顺序为「项目 → 当前分支 → 合并 / 历史图标 → Agent → 界面 → 协作者头像列 → 我的账号」。分支名保留可读文字；工具图标有悬停提示。默认场景树、视口、对象 / 协作检查器三栏，聊天按需打开。

- **分支**：下拉列出 main、tide-lab、greenhouse，当前分支打勾，入口同等。切换后列表显示该分支自己的 Agent 会话。
- **Agent**：数量表示正在工作或验证的 Agent。点击打开完整会话下拉并聚焦搜索。
- **界面**：场景树、属性面板、专注视图。窄窗口通过浮层展开面板。
- **协作者**：真人圆头像；Agent 统一使用机器人图标，以固定颜色区分身份的圆角头像，列表、顶部、会话抽屉保持一致。
- **我的账号**：最右侧独立头像，打开账号与个人偏好菜单。

## 头像与下拉

顶部优先展示正在工作的 Agent；超出容量收进 `+N`，不会丢失列表入口。设计示例有 3 个工作中的 Agent、2 个待处理 Agent、1 个已完成会话。已完成会话保留在“全部”中。

点击头像列展开 368 px 下拉。每行包含头像、会话标题、所属协作者、Agent 职责、更新时间与**文字状态**。标题过长省略，悬停可查看全文。搜索标题、职责、协作者和状态；搜索与“全部 / 工作中 / 待处理”组合使用，无结果显示空态。

| 状态 | 头像 / 文字 | 归属 |
| --- | --- | --- |
| 工作中 / 验证中 | 绿色状态点，文字区分阶段 | 工作中 |
| 待你确认 | 琥珀色状态点 | 待处理 |
| 需处理 | 红色状态点 | 待处理 |
| 已完成 / 空闲 | 无运行状态点 | 全部 |

头像标识绑定会话的 Agent 身份，不随标题或状态变化。正式接入时状态来自实际运行事件，不能根据定时器自动完成。全量列表指当前分支内本人会话及显式共享、本人有权限查看的会话；私有会话的标题、正文、附件均不能通过头像或搜索泄露。

## 点选会话

点击任意行关闭 dropdown，在右侧打开 **430 px 会话抽屉**，标题、头像、状态与列表一致。只读共享会话明确显示所属协作者并禁用发送。关闭抽屉保留草稿与本页演示消息；点击场景返回编辑。对象附件入口连接到同一抽屉，并展示固定分支、对象和坐标。

Esc 优先关闭弹出菜单，然后关闭会话抽屉，焦点返回原触发按钮。Tab 可遍历按钮，菜单内方向键移动，Enter / Space 激活。切换分支关闭当前抽屉，分支与会话身份隔离，本页旧草稿仍保留。

## 验证与边界

主代理完成浏览器点击验证，独立测试角色审查会话映射与交互逻辑。搜索空态、组合筛选、打开正确会话、草稿与消息保留、共享只读、固定附件、分支作用域、Esc 焦点、窄屏面板展开均有本轮验证。详见根目录 [design-qa.md](../../design-qa.md)。

合并、历史、个人偏好等辅助入口展示位置和交互提示，沿用正式工作台后续流程。本稿的场景图、Agent 状态及消息都是演示，刷新会清空本页记录；不代表运行时、持久会话或服务集成验收。
