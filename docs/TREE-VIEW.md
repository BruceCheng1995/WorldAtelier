- 场景根展开以显示总览；预制件定义、实例和下级分支初次默认折叠。定义使用组件图标，实例根使用紫色空心菱形，普通子对象保留类型图标。
- 行高 28 px，缩进 14 px，配轻量层级线；折叠行显示直接子对象数。长名称保留悬停提示，深层树可水平滚动。
- 单击名称选择；Ctrl/Command 增减选择，Shift 连选。箭头仅展开/折叠，Alt 点击递归处理子级。工具栏可全部折叠，Alt 点击全部展开。
- 树只有一个 Tab 入口。上下/Home/End 移动焦点，左右展开/折叠或进出父子层级，Enter/Space 选择，Shift 加方向键连选。加载期间允许 Tab 离开。
- 搜索显示命中项与父级路径、突出名称匹配，计数不含仅作为上下文的父级；清空搜索恢复原折叠和滚动。定位选中对象会清空筛选，仅展开必要祖先并滚动当前面板。
- 每个用户、源稿/运行视图、实际文档各自保存本窗口内的折叠、键盘入口和滚动位置。切文档返回恢复这些状态；刷新页面重新使用默认折叠。源索引更新的加载空窗保留现有树和选择，避免跳动。
- 预制件资源区可单独折叠。目录、选择与导航沿用真实资源，不更改游戏源稿、继承或实例覆盖。
