# 常驻编辑视口与原生场景更新

2026-09-09。属性保存不再默认触发整个编辑 Web 包导出。原工作台仍在 48910；源码事务、Play 与发布入口保持独立。

首次打开使用固定原生编辑器及媒体包。其 `native_content_protocol` 为 `wa-native-editor-content-1` 时，后续修改通过 `native-preview-content` 读取同分支固定源，Godot 在隔离候选中生成无作者脚本的完整 PackedScene。返回当前场景及同源场景闭包的 `.scn` 字节和哈希，现有 Web Godot 从临时内存文件加载，更新当前场景，不重新导出 HTML/JS/WASM/PCK，也不替换 iframe。拖拽预制件使用这一版的实际 PackedScene，避免显示旧包中的预制件。完整 `.tscn/.tres` 文件仍是权威；查询索引只用于对象身份和交互，不重建 JSON 场景。

主视口、对象视口和缩略图共享同一源版本的引擎派生结果。内容准备串行，同版本合并，完成缓存有界；临时候选及执行环境随后删除。前端短时间内的连续请求取消旧等待；过期缩略图不会继续准备旧目标。准备中的旧画面保留，但不接受过期场景操作。真实 `loaded` 回执后才显示场景已更新。相同文档更新保留主视角；场景节点由新的原生 PackedScene 替换。

兼容检查逐一对照原编辑包与目标源文件。场景、资源、脚本及目录元数据可重新派生；媒体、Shader 源、项目设置或其他未知文件有变化时重新准备编辑资源包。新场景引用旧包未包含的媒体，也不复用。原包工具链或编辑器代码改变、场景内容超出传输上限时走完整准备路径。该阶段尚未实现媒体资源的独立增量传输，也不声称每次属性更新零等待；源保存和隔离 Godot 场景派生仍有耗时。

服务端在准备前后核对账号、源可达性、项目/分支和工具链；派生时核对固定编辑器源码及原资源回执。视口核对原编辑包身份、新源版本、资源、原生路径及实际字节哈希。新内容加载失败保留旧场景并显示错误，不推进公共试玩发行，不自动替换正在玩的游戏。

回归入口：`tests/creation/native-preview-content-bridge.test.mjs`（明确的协议双桩，不是运行证明）、`tests/creation/native-editor-content.test.mjs`（独立真实 Godot 派生/加载）、原 `native-editor-build.test.mjs`、`preview-camera.test.mjs` 和 `prefab-thumbnails.test.mjs`。实时验证记录另行附在本页。
