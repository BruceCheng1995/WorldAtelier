## 实现范围

游戏包含观测站、园林、铸炉、城塞四个连通区域，227 个创作对象、46 个敌人（含首领）、三座信标、拾取、战斗、闪避、补给、锻造升级、死亡恢复及持久化进度。角色使用 Blender 制作的蒙皮模型及四段动画，附带合成音频、命中特效、敌人攻击预警和开发状态表现。

中央服务管理账户和成员权限、源码分支、不可变发行、真实构建、资产、世界进度、权威进程及代次、控制权交接、休眠、检查点、升级和恢复。每个世界使用对应发行中的真实 Godot 程序执行玩法，确认后的状态先持久化再回 ACK。内容的来源版本、已经可玩版本和各世界实际版本分开保存。

网页、原生客户端、Godot 编辑器及离线工作区使用同一套内容与协议。当前原生编辑桥支持真实 Node3D 的 X/Z、统一缩放、名称、颜色和 solid 字段；保存场景经 EditorPlugin 导出，再由 watcher 提交、构建和应用。

## 已发现并修复的问题

- 真实 GLB 应用暴露 WebSocket 默认 64 KB 缓冲不足。运行端改为有上界的 32 MiB 缓冲，资产大小受限；快照每端最多一个待消费 ACK，慢端合并到最新完整状态。
- 世界水位曾被活动列表序号覆盖。两者现分字段保存；回退验收独立核对实际世界水位。
- 新程序恢复后玩家尚未重新上线，旧控制封口曾错误地向其发送 move0。现使用已经持久化的冻结检查点/authority epoch 封口，保留旧连接也可完成交接。
- 对象历史根提交的空父引用曾触发 SQLite 参数错误，现明确处理空引用。
- 大对象维护圈曾位于青色选框以内；现在按对象声明的碰撞半径乘统一缩放扩展（不自动测量任意 GLB 的视觉 AABB）。中文字体采用嵌入 Noto Sans SC 的实际字重。
- 敌人预警视觉与命中中心曾有偏差；现在预警、渲染与伤害共用锁定的 attack_area。
- 独立截图发现施工与选中标签叠字；最终版按对象尺寸分开三行标签，额外检查 24 个尺寸/状态组合。
- 桥梁缺少 length/width 曾能通过引擎内容验证，但渲染需要这些字段。0.1.3 在中央源稿与 Godot 验证两处明确拒绝；缺长度、缺宽度、两者都缺均加入回归。
- 持续按住攻击键曾在旧快照期间重复发送。现等待命令 ACK 及对应快照，带有界超时和退避；同一实际原生输入测试由 46 次请求/6 次成功改为 6 次请求/6 次成功。

首次失败记录与修复后记录均保留，详见独立测试说明。一次通过不推定覆盖全部竞态和崩溃时点。

## 当前边界与风险

1. 本机中央服务已验证，提供显式外部 origin 和监听地址配置，但尚未部署公共 HTTPS 服务；“Web 在线”是浏览器连接本机真实中央世界。远程多人需要部署、证书、鉴权运营及网络验证。
2. 已验证两名真实图形客户端合作；五账号用于权限/合并测试。没有做大规模并发、长时间内存趋势、广域网延迟或生产容量测试。
3. 兼容参数、模型和受约束行为模块可在当前世界应用；引擎/宿主变化需要真实新程序交接，有下载和启动延迟。不会把换进程称为原地热更新。
4. 受约束 GDScript 的非法输出检测与回退已验证，release 下没有证据证明能捕获任意 VM 异常；它也不是执行不可信任任意代码的安全沙箱。
5. 游戏目前为 XZ 平面上的定制碰撞与玩法，GLB 用于外观；不支持任意三角网格物理、旋转/Y 轴/非统一缩放的通用原生场景热更。
6. 当前是项目成员共享完整世界快照。按权限裁剪的私有事件视图、分布式租约/跨机权威调度、自动资产保留清理和配额仍属后续设计。
7. 已实际导出并运行 macOS 和 Chrome Web；未验证 Windows/Linux/iOS/Android/Safari。画面验证与控制台检查不能证明声音主观质量、全部 GPU 驱动兼容或持续稳定帧率。
8. 离线内容按三方合并；离线游戏进度独立保留，不自动进入在线世界。不同本地候选使用独立存档，尚无通用候选间存档迁移。
9. Godot 原生编辑器图形验收仍记录两条引擎内部 set_name/list 诊断；没有 SCRIPT ERROR，实际保存、导出与在线应用通过。不能把游戏控制台无异常扩展为编辑器全部日志干净。
10. 已完成的状态周期为人工/自动化编辑器提交、真实构建和实际交付。没有在产品中接入自动执行 Codex/Claude 任务的远程调度服务。
