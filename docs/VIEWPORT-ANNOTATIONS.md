# 视口导航与批注

## 截图划线（2026-09-11）

编辑视口点击 **批注 → 截图划线**。截取当前 Godot 画布后，在固定画面上画自由线、箭头或方框，可选颜色和粗细，支持撤销、重做、清空，以及补充文字说明。Cmd/Ctrl + Z 撤销、Cmd/Ctrl + Shift + Z 重做，Cmd/Ctrl + Enter 保存。Esc 取消当前笔画，再次 Esc 关闭截图；未开始保存时取消不会创建会话。

点击 **加入 Agent 草稿**，划线图片、文字和本批已有对象/空间批注进入同一个新会话，等待用户发送。原会话的草稿和附件保留。已保存图像使用现有的认证图片附件、不可变字节存储和 `localImage` 视觉输入，缩略图可放大，刷新后仍可读取。截图相机、资源和源版本写入简短说明；图中的线条是二维屏幕意图，不伪造世界坐标或编辑对象身份。

截图与绘图不改源稿，不启动 Agent、构建或发布。图片在浏览器合成，按底图像素绘制，再映射到显示尺寸，避免缩放/DPR 引起偏移。最多 200 笔，长笔迹有点数上限；导出遵守每张 5 MB 的已有附件限制。保存失败保留画布和文字供重试，已确认创建的会话会复用，上传结果不确定时按该截图文件名和摘要回读，避免重复附件。已发生部分保存后关闭编辑器，会话列表保留未完成的草稿。

验证入口：`tests/creation/screenshot-annotations-browser.mjs` 使用固定底图与真实 Canvas 检查笔迹、缩放、键盘、取消和保存失败；`tests/creation/screenshot-annotations-workspace.test.mjs` 使用隔离 48921、临时原生工程和静音无界面 Chrome，检查真实 Godot 2D/3D 截图、空间批注合并、上传/PATCH 丢失回执后的重试、旧草稿与刷新隔离。两者串行运行，结束后关闭所建进程。

本轮前者 6 项、实际工作台 7 个检查点通过，图片浏览器回归 5 项、图片 HTTP/权限/存储/Adapter/备份回归 4 项、空间草稿回归 10 项通过。实际工作台证据位于 `.local/creation-verification/screenshot-workspace/browser-62kSqz/`，PNG 导出逐字节等于已绘制画布；源版本不变，未发送消息或启动真实 Agent。Agent 图片输入的现有回归使用明确的模拟执行器，不声称本次验证了真实模型对某条划线意图的理解。正式 48910 的四个前端文件已逐字节对照本机源码，无需重启服务；收据在 `.local/creation-verification/screenshot-annotations/formal-service.json`。

2026-09-10。原工作台入口仍是 <http://127.0.0.1:48910/creation-workspace.html>，编辑器由完整原生 Godot 项目构建。新增批注是会话附件，不插入场景节点、不修改源稿、不触发构建发布或自动运行 Agent。

## 导航

| 操作 | 3D | 2D |
| --- | --- | --- |
| 中键拖拽 | 沿当前相机画面平面平移，旋转不变 | 平移画布 |
| Shift + 中键 / 空格 + 左键 | 平移 | 平移 |
| Alt + 左键 | 围绕选中对象中心旋转；无选中时围绕观察焦点 | 保持现有画布操作 |
| 右键拖拽 | 固定眼点自由转向 | 平移画布 |
| 右键 + WASD / QE | 前后左右 / 上下移动；Shift 3 倍，Alt 0.2 倍 | 不启动飞行相机 |
| 滚轮 / 触控板缩放 | 以光标所在聚焦平面位置缩放 | 保持光标下的画布坐标 |
| 右键按住 + 滚轮 | 调整漫游速度，保持当前位置 | 普通画布缩放 |
| F / Shift + F | 聚焦选中 / 查看全场 | 聚焦选中 / 查看全场 |

“导航”菜单的速度范围为 0.1–1000 m/s，默认 6 m/s，按账号在当前浏览器持久保存。菜单提供对数速度滑杆、转向灵敏度和“轻缓起步 · 快速刹停 / 直接响应”。3D 右键漫游捕获鼠标，保持即时转向；底部显示当前速度、刻度与 Shift / Alt 倍率，退出后短暂保留再隐藏。松开右键、Esc、失焦或浏览器退出捕获都会停止漫游。视口右下角显示引擎实测 FPS，悬停显示帧耗时与 P95。2D 工具栏显示缩放百分比。滚轮支持小数增量，触控板平移与捏合独立处理。独立对象小预览保留左键拖拽旋转。详细设计依据与性能对照见 [3D 漫游与帧率](VIEWPORT-ROAMING.md)。

参考 [Godot 4.6 3D 导航](https://docs.godotengine.org/en/4.6/tutorials/3d/introduction_to_3d.html)。已有对象变换操作柄、源事务及选择层级保留；本次调整相机与画布导航，不声称复刻 Godot 编辑器全部操作设置。

## 批注闭环

1. 编辑模式点击视口顶部“批注”。引擎确认工具状态后开放输入，避免第一次点击意外选择或移动对象。
2. 明确选择“选对象”“空间描点”“框选对象”“笔刷”或“三维区域”。笔刷可切换为选择对象或描述空间区域。气泡显示对象列表和坐标，输入描述后保存。支持 Cmd/Ctrl + Enter 保存、Esc 取消当前输入、列表编辑和逐条删除。
3. 批注期间仍可平移、环绕、缩放。记录的世界坐标、体积和成员不随视角变化；相机只改变标记投影。源节点、选择和变换不因批注而更改。
4. “完成批注”或退出模式将多条记录原子写入**一个新 Agent 会话的输入草稿**，打开该草稿并等待用户发送。带有未保存文字的当前气泡会先保存；空输入需取消或补充。切换场景、分支或离开工作台也会先完成当前批次。
5. “⋯ → 取消全部”丢弃本机当前批次，不创建会话。已保存批注按账号/项目/分支/资源保存在本机，刷新后可继续；未保存的气泡文字不持久化。
6. 点击工具栏“⋯ → 复制全部”或 Agent 草稿中的“复制批注”，可粘贴到同一项目和分支下的其他自有 Agent 输入框。剪贴板包含可读文字及带版本的引用数据；服务重新验证并创建目标会话的附件，保留原有草稿，不自动发送。
7. 用户发送后，现有开发状态投影将区域成员接入同一对象描边与共享选中标签组件，并附加位置/区域处理标记。运行结束后清除处理标记；私人批注正文不进入公共协作状态。

## V2 空间批注（2026-09-10）

| 工具 | 选择规则 | 可调整内容 |
| --- | --- | --- |
| 选对象 | 命中最近可见模型的真实三角表面；未命中则提示切换空间描点 | 批注文字 |
| 空间描点 | 与 XZ / XY / YZ 固定工作平面相交，可直接在中心创建，无需物体承载 | XYZ 数值、坐标轴或平面操作柄 |
| 框选对象 | 仅收集与屏幕矩形相交的对象包围范围；不创建空间区域 | 批注文字 |
| 笔刷 → 选择对象 | 收集画笔覆盖的投影对象包围范围 | 屏幕笔刷大小、批注文字 |
| 笔刷 → 描述空间区域 | 在固定平面点涂或画出闭合足迹，再沿法线赋予厚度 | 世界笔刷半径、XYZ 位置、厚度 |
| 三维区域 | 拖出工作平面上的底面，并赋予厚度；也可在中心创建 | XYZ 中心、XYZ 尺寸、三轴移动、六个面柄拉伸 |

空间工具显示固定工作平面网格。“偏移”决定平面位置，区域从这个平面沿正法线延伸。“正对平面”切换到对应正交视图；“聚焦批注”找回视野外的点或区域。空间气泡固定在视口右上方，避免输入面板跟随视角跳动；范围和操作柄留在 Godot 场景中。拖动时 Shift 精调、Ctrl 按 0.25 m 吸附；Esc 撤销当前拖动，再次 Esc 取消当前气泡。取消或切换工具不会留下幽灵操作柄。旧源版本的本机记录只允许修改文字，保留捕获时的坐标。

设计参考 [Blender 3D Cursor 的显式空间坐标](https://docs.blender.org/manual/en/4.4/editors/3dview/3d_cursor.html)和 [Annotation 的放置平面](https://docs.blender.org/manual/en/3.1/interface/annotate_tool.html)，将表面拾取、固定工作平面和空间操作柄分开。导出的编辑视口使用现有运行时变换操作柄；Godot 的 EditorNode3DGizmo 属于编辑器 API，不能直接放进 Web 导出。

### 范围与附件语义

- 3D 点选使用 [Godot TriangleMesh BVH](https://docs.godotengine.org/en/4.6/classes/class_trianglemesh.html)；穿过模型包围盒中的空洞不会误选对象，不要求场景预先带碰撞体。隐藏节点、显示层外节点与相机裁剪范围外表面排除。此路径针对静态编辑 Mesh；不声称准确拾取骨骼、顶点着色器变形或透明纹理的可见像素。
- 对象笔刷/框选仍按可见节点的屏幕包围范围选择，不做逐像素遮挡判定。空间笔刷和三维区域按**世界 AABB 与体积相交**收集对象，包含区域中的屏外对象；隐藏节点排除。倾斜或凹形模型的包围盒可能产生额外成员，气泡列出实际捕获成员供检查。
- `object` 是单个对象；`objects` 是对象集合；`point` 是独立空间描点；`region` 包含 `box` 或 `prism` 几何。Box 保存中心和 XYZ 尺寸；Prism 保存闭合世界足迹、工作平面、偏移和厚度。相机只是辅助上下文，不参与后续成员重算。原先视图区域附件保留原有语义，不重解释历史记录。
- 2D 使用真实画布逆变换坐标，单位 px；3D 使用 m。独立预制件保留自身原点。捕获固定源版本、资源、完整实例路径、成员源姿态、坐标与区域边界；后续源变动不改写附件，Agent 修改前仍须读当前源版本并走原生源事务。
- 一批最多 64 条、合计 512 个对象，每条最多 2000 字符。空间笔刷足迹最多 96 点，显示与成员查询使用同一简化轮廓；过长输入轨迹要求拆分。调整区域超限会清除待定成员、禁用保存，缩小到合法范围后恢复。服务检查写权限、分支祖先链、形状和全部成员身份，失败整批回滚；批次收据防止重试创建重复会话。服务根据固定原生索引验证对象身份，几何相交由真实编辑运行时计算，不冒充服务端重新运行几何求交。
- Agent 默认上下文带坐标、尺寸/厚度、成员引用和描述；完整轮廓留在附件文件按需读取，不展开原始资产。退出批注产生一个新待发送草稿，复制粘贴保留固定空间信息；运行时的对象描边、空间线框和状态提示来自实际 Agent 开发投影。
- API：`POST projects/:p/branches/:b/annotation-drafts` 和 `POST sessions/:sid/annotation-imports`。健康响应 `viewport_annotations: 2`、`annotation_context_version: 4`；历史附件仍可读取和复制。

### 性能设计

- Mesh 索引按编辑文档/版本建立，BVH 按共享 Mesh 缓存；先做包围盒粗筛，再调用 Godot C++ 三角树。画笔不再对轮廓每个点递归遍历模型和逐三角求交。
- 原生批注线框合并为一个缓存 Mesh，带轻量穿透提示；只有批注内容改变才重建。静止批注不持续重建几何或发送投影。相机移动时最多 20 Hz 更新网页标记坐标；网页重用同一批标记 DOM。
- 画笔预览只计算平面轮廓；成员查询在收笔或完成范围调整时执行，不放进逐帧循环。

## 验证

`tests/creation/annotation-spatial-engine.test.mjs`、`viewport-navigation-engine.test.mjs` 与 `viewport-annotations-engine.test.mjs` 使用隔离 Godot headless / Dummy 音频，验证真实输入、相机坐标、区域成员与源稿不变。`viewport-annotation-drafts.test.mjs` 使用真实 SQLite 和服务路由，验证权限、原子保存、重试、跨会话粘贴及开发状态投影；该开发状态用明确的运行记录 fixture，不是一次真实付费 Agent 执行。

`tests/creation/viewport-annotations-browser.test.mjs` 在独立 48921 与临时数据中加载原工作台、构建原生 Web 编辑器，以无界面静音 Chrome 真实鼠标/剪贴板操作验证 2D 点选/框选、3D 对象笔刷、任意描点、XYZ/尺寸/厚度编辑、相机环绕、空间点涂、取消删除、单一待发送草稿、粘贴与刷新。它不自动发送 Agent、不修改正式游戏、源版本保持不变。V2 运行记录和截图位于 `.local/creation-verification/annotation-v2/`；测试服务与浏览器结束后关闭。最新具体结果见该目录的 `delivery.json`。


V2 独立几何与输入探针通过 126 项断言，旧批注回归 82 项、导航回归 264 项通过；SQLite/附件/源选择/原生桥接等组合回归通过 45 个测试。126 项中包含真实坐标轴移动、面柄拉伸保持对侧面固定、取消与迟到鼠标事件、超限禁存/缩小恢复、静止 120 帧不重复投影或重建 Mesh、显式空间点涂与相机聚焦。结果及当前脚本哈希见 `annotation-v2/independent-validation.json`。

帧率对照使用同一固定双 Mesh 原生场景、同一官方 Web 导出路径、1280×800 CSS 视口、DPR 1/2、静音无界面 Chrome 的 Apple M5 Pro / ANGLE Metal。每项取 179 个帧间隔：

| 场景 | V1 P95 | V2 P95 |
| --- | --- | --- |
| 空视口：静止 / 相机转向 | 16.7 ms | 16.8 ms |
| 64 个空间描点：静止 / 相机转向 | 16.7–16.8 ms | 16.7–16.8 ms |
| 64 个三维框：静止 / 相机转向 | V1 无此工具 | 16.7–16.8 ms |
| 64 个空间笔刷区域（每个 96 点）：静止 / 相机转向 | V1 无此工具 | 16.7–16.8 ms |

本机这一场景约为 60 FPS，未观察到批注导致明显帧耗时回退；这是独立 Web 渲染诊断，不代表所有游戏、模型复杂度或设备都保持 60 FPS。CPU 探针另外在 1000 Mesh 下测得热拾取 P95 约 0.7–0.8 ms、体积成员查询约 1.3 ms。16640 三角 Mesh 首次 BVH 约 3.6 ms、缓存后约 0.005 ms；静止帧和相机移动均不重复建 BVH。完整样本见 `perf-baseline/report.json` 、`perf-current/report.json` 和 `perf-prisms/report.json`，硬件时序不作为跨设备 CI 硬阈值。
