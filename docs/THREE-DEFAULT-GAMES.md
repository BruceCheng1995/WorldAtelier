当前分发目录的版本为 `a1d80e2ccfd598aed4b047d8575562f450117cf36baf7fc78bc14619d4fb04f0`。每款使用同一隔离源修订构建真实 Three 和 Godot 客户端，然后分别操作。俄罗斯方块检查源布局、可视位置、按钮点击和撤销。植物大战僵尸从封面按 Enter 进入花园。两端都执行了玩法输入、冻结、截图点选和恢复。逐款操作、源与运行时身份、画面及复跑入口见[浏览器动作矩阵](../.local/creation-verification/three-nine-actions-20261102/final/RENDERED.md)和[源操作记录](../.local/creation-verification/three-nine-actions-20261102/final/README.md)。测试中的实际输入、引擎观察和候选对象分别记录，范围限于列出的动作。

## 初次迁移

2026-11-02。分发版本 `90794d99e621cdc76ac056637774c3882c0a12c6f0993196f0c69e881ab6589e`。八个既有主干保留 625 个原文件的路径和字节，增加 47 个 Web 作者文件。原生节点地址、资源名称、知识、公开属性和实例覆盖逐项核对。Web 和 Godot 包使用相同的项目源身份。Godot ZIP 包含完整源文件，导出器为 `project.godot` 配置 GameRuntime 启动入口。

在本机工作台选择游戏主干，使用视口「更多 → 打开 Godot 对照窗口」，可以从同一源版本分别浏览和独立试玩，返回当前源稿后继续编辑。完整编辑、游戏输入、显式发布和已有发布指针各自使用原权限。「构建与导出」仍提供 Web 包和 Godot 工程。首次派生复杂模型需要隔离的 Godot 导入器，后续按固定输入复用。

## 构建和证据

在隔离用户数据中测试固定源，读取本机正式库中的最终主干，再按整份 `source_identity` 对齐。不同库产生的 revision 和 build ID 各自记录。九个默认工程中另一个主干「贪吃蛇」的旧对照记录继续保留。本次维护只在正式库的上述八个主干各追加了一个子版本。

本机证据目录为 `.local/creation-verification/three-defaults-20261102/`。其中 `acceptance/README.md` 和 `acceptance/index.json` 包含逐款操作、固定构建、真实 Agent 帧序列与复验条件。八款的 16 个下载包位于 `packages/`，每款均有哈希、字节数和源版本回执。运行 ZIP 原件的浏览器检查在 `packages/standalone.json`，Godot ZIP 文件核对在 `packages/native-file-readback.json`。

M5 Pro 测试中的「小巷漫步」空缓存编辑时间约 35 秒，热加载约 1.7 秒。同一轮「TPS」和「兽人必须死」的热加载约 1.0–1.2 秒。这些时间包括固定内容进入工作台的等待，各游戏的包体、首次派生和浏览器资源缓存不同。
