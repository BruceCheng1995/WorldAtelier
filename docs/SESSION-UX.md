# Agent 会话交互简化

2026-09-08，更新原工作台 `http://127.0.0.1:48910/creation-workspace.html`，实现位于 `apps/creation-workspace/`。

## 操作流程

| 场景 | 新流程 |
| --- | --- |
| 新建会话 | 顶部或聊天标题栏点「+」→ 输入创作需求 → Enter 发送 |
| 返回聊天 | 顶部 Agent → 当前会话 |
| 切换会话 | 点机器人头像旁的会话标题 → 搜索或选择会话 |
| 修改名称与可见性 | 标题栏「设置」→ 编辑所需项目 |

创建前取消必填名称弹窗，准备输入从四次点击及命名降为一次点击。新会话立即持久保存，默认公开（项目成员可见），私有需手动设置；已有会话保持原可见性；首条消息成功提交后，从其内容生成最多 36 字的标题。名称仍可在设置中编辑。附加上下文、模型、思考强度和执行权限沿用现有能力。

聊天标题、会话切换、设置及窗口操作合为 56 px 一行。会话列表改为搜索浮层，关闭时不占正文高度；选中、点击外部或 Esc 关闭。Esc 先关闭设置或会话浮层，再关闭聊天。机器人头像和顶部协作者列表继续使用真实会话与状态。

## 可靠性

- 同一账号和分支的新建请求合并；当前空白私人会话再次点「+」会复用。已有草稿、附件、消息、目标或运行的会话不复用。
- 切换前保存草稿，异步返回不抢占已经切换的账号、分支或会话。
- 发送保持单个在途请求及原有不可变消息标识；网络结果不确定时不自动再建或再发。
- 首次执行器绑定成功后才保存自动标题，避免后台首次绑定覆盖标题；首次提交结果不确定时暂禁改名。
- 已确认标题与服务器更新时间合并，防止较旧读取响应使标题回退；更晚的服务器修改优先。
