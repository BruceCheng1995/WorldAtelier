# 对象检查器与参数控件

2026-09-10 更新。原工作台 `apps/creation-workspace/`，入口仍为 48910。

对象面板顺序：顶部唯一名称与 Agent 操作 → 当前作用范围及实例来源 → 空间与变换（Control 为布局与变换）→ 可调属性 → 功能描述 → 独立模型预览。名称双击或键盘 Enter/F2 进入编辑，Enter/失焦保存，Esc 取消，空名称不提交。只读时不能重命名。预制件顶部改资源名称；场景实例改当前实例名，内部节点仍按完整地址改覆盖。名称变化不改历史附件。名称前复用树中的预制件组件／实例空心菱形图标。删除入口使用顶部名称右侧的垃圾桶图标，悬停明确显示所选对象名称与可撤销提示；保留原删除范围及层级子内容复选设置。

空间区默认展开，并在当前页面内按用户、分支、资源、模式与所选对象记住折叠状态。原生对象按自身实际布局或空间属性显示；所在场景的系统分类不能隐藏子对象的变换。坐标、旋转、缩放和暴露参数都使用 `semantic-inspector.js` 的 `createParameterControl(document, spec, value, options)`。桌面属性行与树行统一为 28 px，普通输入与向量外框均为 24 px（向量内输入 22 px）；84 px 标签列和 20 px 恢复列固定占位，数值列保持对齐。长名称省略，悬停显示全名与说明。向量 X/Y/Z 用颜色和字母共同区分，旋转显示度，空间为相对父级的局部坐标。实例挂载偏移单独折叠，不与内部节点局部变换混淆。

四维向量使用两列两行，避免窄面板中每个数值过窄。Control 锚点与偏移显示“左／上／右／下”，布局预设与恢复入口放在同一工具行。容器管理字段、只读字段及等待实际布局测量的禁用状态沿用原行为。

功能描述默认折叠，按完整对象身份记住状态，已有未保存草稿保留。说明标题可悬停预览内容，实例说明仍只读。模型预览位于面板下方，可用标题按钮折叠；折叠保留现有 iframe 和相机，不重新创建预览。40 px 分类栏和紧凑名称栏固定在滚动面板顶部。“对象／协作”两页保留。

| 控件 | spec.type | 使用场景 |
| --- | --- | --- |
| 文字 | string | 标签、提示文本 |
| 小数 | number | 速度、时长、距离；支持 min/max/step/unit |
| 整数 | integer | 数量、次数 |
| 开关 | boolean | 是否启用 |
| 选项 | enum | 有限枚举，保留原始值类型 |
| 二、三、四维向量 | vector2 / vector3 / vector4 | 位置、角度、尺寸，逐轴输入 |
| 显式颜色参数 | color | 现有游戏主动暴露的颜色参数；保留色值和 HEX 输入 |

删除的是对象通用颜色属性及其保存/恢复入口，已有游戏行为主动声明的颜色参数仍按原语义显示。通用对象面板的“固定上下文到指定会话”选择器及按钮已删除；会话输入本身的对象引用和历史附件保持兼容。

控件只负责呈现，宿主负责持久化。变换沿用输入时开始编辑、完整 TRS 原子提交、Euler 转 quaternion、版本与地址保护；恢复变换同样经现有提交和撤销路径。暴露参数沿用属性绑定、权限、默认值及覆盖规则。`rename_resource` 专用事务只修改资源 name/version，严格校验名称和 expected_version，产生带版本条件的逆操作。

布局参考：[Godot Inspector](https://docs.godotengine.org/en/stable/tutorials/editor/inspector_dock.html) 的属性分组与恢复入口，以及 [Figma 右侧属性栏](https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar) 与 [位置、旋转和尺寸属性](https://help.figma.com/hc/en-us/articles/360039956914-Adjust-alignment-rotation-position-and-dimensions) 的紧凑排列。具体密度与本工作台的树视图保持一致。
