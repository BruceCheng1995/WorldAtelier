# 会话验证流程移除与消息中心

2026-09-08，用户纠正：移除的是 session 顶部“目标与自动检查”流程，保留 `/goal` 原生持续目标。

Agent 通过现有 `asset_publish` / `world_apply` 保存并应用修改。平台不再等待 Godot 技术检查或独立 Agent 验收；Agent 自行判断需要哪些测试。Play、独立 Web、导出继续消费固定的游戏源码及完整资源依赖，已运行游戏仍遵循现有重新开始或显式共享世界应用语义。

- 删除会话顶部的目标选择、Agent 开发 / Godot 技术检查 / 独立 Agent 检查阶段、重试检查、检查依据及历史人工记录界面。
- 删除订阅、源修改、合并、开发完成、权限变更和服务恢复触发的自动检查调度，以及独立检查 Agent 执行器。
- 保留普通会话、`/plan`、`/goal`、长期执行线程、附件、取消与真实权限请求。目标完成状态来自原生执行器，不进入“等待检查”。
- `game_validate` / `workspace_test` 可由开发 Agent 按需调用，不是自动工作流或应用门槛。显式共享权威世界的版本兼容和控制权限保持原有协议。
- Inbox 保留真实执行、工具、运行、构建、客户端和协作错误及权限请求。旧自动检查消息不计数、不显示、不标记资产，不能触发重试或验证请求。
- 旧 `/creation-api/goals/*` 验证接口与 `/creation-api/automatic-checks/*` 返回 410。原生 Goal 仍由会话执行接口提供。
- 历史验证数据、证据与固定工程保留用于备份兼容；不迁移为新的检查结果，不重启历史检查。旧实现证据见 `AUTOMATIC-VERIFICATION-REPORT.md`，不是现行产品要求。
